# v1.0 实现说明

版本定位：本地可演示的 ddEC D6 院外随访 Demo。全部为虚构患者与本地模拟数据。

## 本次实现

- 重置后从通用首页开始；完成身份绑定、知情同意与 ddEC 选择后，自动进入专项并弹出 D6 来电。
- 时间线按点击节点查看：D-1/D1/D2 已完成且不可重做，D6 可操作，D8/D10 仅可查看。
- D6 仅保留检验检查上传与详细语音随访；随访逐题采集 8 项，结束后生成患者核对总结卡，可回传团队。
- 体温超过 38.5℃或出现确认的红旗症状，完成全部问题后提示就近急诊并生成红色风险卡；工作台支持标记“已联系患者”。
- 工作台包含队列、风险、沟通、提醒、日志、质检、AI 审核与恢复看板的可点击演示模块。

## 医学边界

基于飞书《复旦肿瘤乳腺外科患者化疗随访知识库》与已确认规则。AI 只做采集、归纳与风险预审；是否化疗、延迟、停药、剂量和处方均由汤主任团队结合原始资料决定。

## 待临床确认

本期之外的方案节点、黄色阈值的其他项目、医生端真实响应时限、消息与电话接口均不在本地 Demo 中实现。
