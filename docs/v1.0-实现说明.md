# v1.0 实现说明

版本定位：本地可演示的 ddEC D6 院外随访 Demo。全部为虚构患者与本地模拟数据。

## 本次实现

- 重置后从通用首页开始；完成身份绑定、知情同意与 ddEC 选择后，自动进入专项并弹出 D6 来电。
- 时间线按点击节点查看：D-1/D1/D2 已完成且不可重做，D6 可操作，D8/D10 仅可查看。
- 各节点除医院检验检查上传外均以语音任务呈现：D-1、D1、D2 的既往语音任务已完成且可查看只读总结；D6 可完成血常规上传和详细语音随访；D8、D10 的报告上传与语音随访均只读锁定。
- D6 随访逐题采集 14 个患者可理解的症状/检查组，结束后生成患者核对总结卡，可回传团队。
- 语音随访只需点击一次“开始通话”；随后助手逐题播报并自动连续监听，直至通话结束。仅在浏览器无法识别语音时显示文字演示输入兜底。
- 症状采集按单一症状组逐题确认，使用患者可理解的描述（如“憋气、喘不上气”“尿频、尿急、尿痛”）；每题回答后以“好的，了解了。再问一下……”承接下一题。
- 注册时采集患者方便接听电话的时段；D6 仅展示“待接听 · 汤主任助手来电”主按钮，接听后进入全屏电话模拟界面。
- 体温超过 38.5℃或出现确认的红旗症状，完成全部问题后提示就近急诊并生成红色风险卡；工作台支持标记“已联系患者”。
- 工作台包含队列、风险、沟通、提醒、日志、质检、AI 审核与恢复看板的可点击演示模块。
- 医生端首页采用“团队横幅—风险/质量双核心卡—患者队列/恢复看板/处理日志快捷入口”的工作台布局；点击后进入对应的化疗随访二级模块。

## 医学边界

基于飞书《复旦肿瘤乳腺外科患者化疗随访知识库》与已确认规则。AI 只做采集、归纳与风险预审；是否化疗、延迟、停药、剂量和处方均由汤主任团队结合原始资料决定。

## 待临床确认

本期之外的方案节点、黄色阈值的其他项目、医生端真实响应时限、消息与电话接口均不在本地 Demo 中实现。
