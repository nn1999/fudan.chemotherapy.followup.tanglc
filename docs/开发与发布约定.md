# 开发、发布与备份约定

## 三份备份

1. 本地：`/Users/ningchun/Desktop/复肿化疗随访/` 是唯一可编辑开发目录。
2. GitHub：`nn1999/fudan.chemotherapy.followup.tanglc` 保存源码、每次发布包与版本记录。
3. 飞书：PRD 保存需求、临床规则与验收口径。

## 目录职责

- `app/`：当前可编辑的 Demo 源码；当前以 v0.9 为基线。
- `releases/`：待发布或归档的独立静态包。
- `github-pages-fudan-tang-ddEC-v0-9/`：已发布 v0.9，不直接覆盖。
- `docs/`：飞书 PRD 入口、发布记录与本地协作约定。

## 每次迭代

1. 先以飞书 PRD 确认功能与临床规则。
2. 在 `app/` 实现并本地验收；生成发布包放到 `releases/`。
3. 将源码与发布包提交、推送 GitHub；再发布 GitHub Pages。
4. 在飞书 PRD 记录版本、验收结果和 Git 提交号。

不要把 `~/.codex/.chatgpt-projects/` 作为源码目录；它是可被同步重建的项目镜像。
